# macOS Dock Component
A professional, sleek macOS-style dock built with **Next.js**, **Tailwind CSS**, and **Framer Motion**.

Crafted by **Prathamesh Naidu** as an educational resource for fluid UI interactions.

## Features
- 🚀 **Next.js 14+** support
- ✨ **Framer Motion** physics-based scaling
- 🎨 **Tailwind CSS** styling
- 📱 Responsive and professional design
- 🛠️ Easily customizable via JSON configuration

## Installation

This is an educational component. You can integrate it into your project by copying the `components/Dock.tsx` file.

### Prerequisites
Make sure you have the following dependencies installed in your project:
```bash
npm install framer-motion lucide-react clsx tailwind-merge
```
